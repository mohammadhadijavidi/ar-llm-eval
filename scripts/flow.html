ar-llm-eval · how it worksكيف يعمل المعيار

من مهام مكتوبة يدوياً إلى لوحة نتائج: كل خطوة حتمية وقابلة لإعادة الإنتاج، ما عدا استدعاء النموذج نفسه.

١. المهام

tasks/*.yaml
  • ٧٣ بنداً بذرياً مكتوباً يدوياً
  • فصحى + لهجة خليجية/إماراتية
  • تشكيل، صرف، إملاء، سياق إماراتي
  • لكل بند إجابة مرجعية
◀

٢. طبقة المزوّدين

providers.py
  • openai openrouter groq
  • ollama lmstudio (محلي)
  • anthropic
  • mock: نماذج محاكاة للعرض فقط
◀

٣. المصحّحات

checks.py · normalize.py
  • نسبة خطأ التشكيل DER
  • الجذر، المطابقة، الأرقام، JSON
  • مؤشرات اللهجة مقابل الفصحى
  • توحيد الهمزات والتطويل والأرقام
◀

٤. النتائج واللوحة

results/*.json → leaderboard.html
  • متوسط الفئات بأوزان متساوية
  • تقسيم فصحى / خليجي
  • بصمة نسخة المهام
  • وسم DEMO لكل نتيجة محاكاة
اختبار ذاتي: الأمر ar-llm-eval validate يمرّر كل إجابة مرجعية على مصحّحاتها، ويفشل إن لم تحصل على ١٠٠.
الأمانة: لا ننشر درجات لم نقِسها. نتائج mock تظهر دائماً بوسم DEMO ولا تمثّل أي نموذج حقيقي.
